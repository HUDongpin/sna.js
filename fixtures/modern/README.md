# Modern algorithm oracle fixtures

`oracles.json` is a deterministic development/test fixture generated by
`scripts/generate-modern-oracles.py`. It is not loaded by the production
package and Python is not a runtime dependency of `@peterhudongpin/sna.js`.

The primary numeric oracle is NetworkX 3.6.1. python-igraph 1.0.0 independently
cross-checks PageRank, a non-degenerate HITS case, and modularity whenever the
two libraries use directly comparable graph conventions. NumPy and SciPy are
also pinned because NetworkX delegates PageRank/HITS and structural-hole
calculations to those numerical libraries.

## Regeneration

Use CPython 3.13 and the exact oracle-only requirements:

```sh
python3.13 -m venv .venv-oracles
.venv-oracles/bin/python -m pip install -r scripts/modern-oracle-requirements.txt
.venv-oracles/bin/python scripts/generate-modern-oracles.py
```

The generator asserts every pinned version and writes JSON with a stable node
order, a fixed seed, a corpus SHA-256 receipt, and fourteen significant digits.
Running it twice in the same locked environment must produce byte-identical
output.

## Corpus and gates

The corpus contains empty, singleton, path, star, cycle, complete,
disconnected, directed SCC/WCC, asymmetric directed HITS, weighted, self-loop,
complete bipartite, seeded planted-partition, and Zachary karate graphs. The
fixture gates PageRank (including personalization and dangling redistribution),
HITS, harmonic centrality, triangles,
clustering, assortativity, mixing matrices, Burt structural holes, explicit-pair
link prediction, modularity, and partition quality.

The planted-partition fixture records only the known generating blocks for
modularity and partition-quality checks. It does not record NetworkX or igraph
community-detection membership as an oracle; randomized algorithms continue to
use the invariant gates below.

Random community algorithms are not gated by exact external memberships.
Their tests instead require a legal partition, exact same-seed repetition,
recomputed quality, connected restricted-Leiden communities, and matching
Infomap code length.

## Explicit compatibility notes

- NetworkX and igraph use different undirected self-loop transition/degree
  conventions. The self-loop case therefore records NetworkX as the primary
  oracle and an explicit igraph compatibility note instead of claiming a false
  cross-check.
- NetworkX 3.6.1's all-nodes sparse shortcut for weighted `effective_size`
  differs from its documented node-wise Burt formula. The generator passes an
  explicit node list, selecting the documented formula; this choice is recorded
  in fixture provenance.
