# Capability and validation matrix

This matrix distinguishes implementation from scientific validation. A function can exist without being claimed equivalent to an external package.

## Validation labels

| Label | Meaning |
|---|---|
| **R parity-gated** | Replayed against values generated by R `sna` 2.8 from the committed provenance fixture. |
| **External oracle-gated** | Deterministic numeric results are compared with pinned NetworkX 3.6.1 and, where definitions align, python-igraph 1.0.x fixtures. |
| **Invariant-tested** | Mathematical identities, validity, error boundaries, deterministic seeds, and/or hand-computed graphs are tested; exact external membership need not match. |
| **Experimental** | Implemented with a disclosed limitation that prevents claiming full reference-algorithm equivalence. |
| **Deferred** | Intentionally absent from 0.5.0; no placeholder masquerades as an implementation. |

## Modern algorithm support

| Function/family | Directed | Weighted interpretation | Self-loops | Validation and notes |
|---|---|---|---|---|
| PageRank | Yes | Non-negative strength; binary opt-out | Accepted | **External oracle-gated**; personalization, dangling vectors, normalization, convergence, progress, cancellation. |
| HITS | Yes | Non-negative strength; binary opt-out | Accepted | **External oracle-gated** up to eigenvector sign/normalization conventions; L2 invariants. |
| Harmonic centrality | Yes, in/out | Strength becomes inverse distance; binary hops | Ignored as zero-length self reach | **External oracle-gated** on aligned distance semantics. |
| Triangles | No | Binary | Ignored | **External oracle-gated** and triangle/degree identities. |
| Clustering | Yes | Binary; Onnela weighted; Fagiolo directed | Ignored | **External oracle-gated** on aligned definitions; hand-computed weighted/directed cases. |
| Degree assortativity | Yes, in/out/total | Binary degree or strength degree | Counted by endpoint-degree rules | **External oracle-gated**; undefined zero-variance results are `null`, not `NaN`. |
| Attribute assortativity/mixing | Yes | Binary edge endpoints | Included by endpoint rules | **External oracle-gated** for string/number categories and finite numeric values. |
| Burt constraint/effective size | Yes, weak neighbor union | Binary or non-negative strength | Excluded from neighbor sets | **External oracle-gated** where definitions align; isolates return `null` plus warning. |
| Greedy modularity | No | Non-negative strength | Supported by modularity | **Invariant-tested**; heuristic merge search, no global-optimum claim. |
| Louvain | Yes | Non-negative strength | Supported | **Invariant-tested** for partition validity, seed stability, and modularity recomputation; exact membership is not cross-library gated. |
| Restricted Leiden | No | Non-negative strength; modularity or CPM | Supported | **Experimental** and **invariant-tested**; connected communities; no gamma-density/subset-optimality claim. |
| Two-level Infomap | Yes | Non-negative flow strength | Supported | **Experimental** and **invariant-tested**; true seeded trials and map-equation recomputation, but no hierarchical/Markov-time/multilayer modes. |
| Girvan–Newman | No | Binary, or strictly positive distance | Ignored for splitting | **Invariant-tested**; exact betweenness per removal; mandatory stop bound. |
| Modern label propagation | Weak view | Non-negative strength | No neighbor effect | **Invariant-tested**; seeded stable output. Distinct from the deterministic legacy root function. |
| k-clique percolation | No | Binary topology | Ignored | **Invariant-tested** overlapping memberships; exponential enumeration guard. |
| Five link-prediction scores | No | Binary topology only | Rejected | **External oracle-gated**; candidate pairs required. |

## Unsupported/deferred semantics

| Area | 0.5.0 status |
|---|---|
| Parallel-edge/multigraph algorithms | **Deferred.** Input duplicates are rejected unless explicitly collapsed at construction. |
| Mixed directed/undirected graphs | **Deferred.** Cast explicitly before analysis. |
| Signed clustering/community/balance | **Deferred.** Negative strengths are rejected by affected modern algorithms. |
| Full reference Leiden guarantees | **Deferred.** `leiden-restricted` is clearly marked experimental. |
| Hierarchical/full Infomap | **Deferred.** `infomap-two-level-greedy` is clearly marked experimental. |
| Temporal/event/spell networks | **Deferred.** |
| Multilayer/multiplex networks | **Deferred.** |
| ERGM/TERGM/relational-event estimation | **Deferred** to a separate add-on because estimation, convergence, GOF, and degeneracy need their own contract. |
| GraphML/GEXF full format support | **Deferred.** Existing DOT/NOS/DL helpers are unchanged. |
| GPU/WASM execution | **Deferred.** |

## Release gates

The 0.5.0 release gate requires all of the following, not just a passing unit suite:

- R parity fixture count and README marker match;
- Node 20/22/24 tests and strict TypeScript declarations;
- modern coverage thresholds (lines/functions/statements at least 95%, branches at least 90%);
- deterministic 10,000-node/100,000-edge CSR/CSC performance and invariant receipt;
- real Chromium ESM and Worker execution;
- packed ESM, CJS, TypeScript, and no-Three root consumers;
- per-entry API snapshots and package size budgets;
- deterministic synthetic sample regeneration;
- npm tag/version/SHA identity, trusted-publishing provenance, registry integrity, clean install, CDN import, and GitHub Release receipt.
